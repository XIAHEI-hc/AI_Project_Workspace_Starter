# 跟踪与回顾

1. 核对上次状态、来源与本次新证据；只更新受影响实体。
2. 记录阻塞内容、负责人、下一动作和复查条件。问题是已发生事实，风险是可能事件。
3. 进度报告区分已做、待验证、下一步与决定请求；不要以完成任务数计算项目价值。
4. 阶段调整写出旧计划、改变原因、被挤占事项及新计划；追加变更记录。
5. 回顾时识别过期事项、没有依据的“已完成”和仍未验证的收益；按需加载 `../evidence/SKILL.md`。
