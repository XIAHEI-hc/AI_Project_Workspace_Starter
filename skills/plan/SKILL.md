# 路线图与排序

1. 先看当前阶段目标、完成标准、阻塞、已承诺的工作和人员可用性。
2. 给新事项判断 `现在做/后续/待澄清/暂缓`，依据价值、急迫性、依赖、准备程度、风险与投入；说明不确定项，避免假精确分数。
3. 需要插队时指出它挤占什么、对当前里程碑的影响。没有足够依据时提出可验证的启动条件。
4. 里程碑写成可验证的结果，任务写成动作；明确依赖和验收证据。长期方向可以只写方向和触发条件，不虚构日期。
5. 若目标或外部承诺发生改变，记入决策并由有权人决定。随后加载 `../publish/SKILL.md` 更新页面。
