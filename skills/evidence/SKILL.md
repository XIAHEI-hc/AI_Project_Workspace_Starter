# 验收与收益

1. 为每个里程碑逐条对照验收条件和证据内容；链接存在不等于证据支持结论。
2. 区分已提交、已验证、已部署、已验收、收益已确认；任何前一状态不自动推动后一状态。
3. 记录证据来源、时间、版本、环境、核实结果及缺口。反例与失败日志同样保留。
4. 收益先记录预期和比较方法；实际观察值、基线、时间段及归因局限必须可见。没有数据时保持 `待验证`。
5. 宣告验收或收益达成需有权人的决定与依据；用户已明确授权时执行并写入决定记录。
